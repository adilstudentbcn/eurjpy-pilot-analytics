## Analysis rules

- Report counts and unique sessions separately.
- Calculate each rate only when its denominator is visible.
- Keep each price variant separate.
- Do not pool asset categories until category counts and workflow differences are reported.
- Treat simulated UX findings as interface hypotheses, never as funnel rates.
- Record missing or failed events explicitly.
- Do not publish a market-size or conversion conclusion from this pilot alone.

# Simulated user journeys — multi-market trading intelligence terminal

## Method

Notebook Block 8c simulates a conditional journey:

`reached → sets a first habit → keeps it a week → slips → recovers → reaches a value moment → pays`

The original notebook uses Ritmo habit-app event rates by age band and adds assumed recovery behaviour. For this product, the analogous journey is:

`reached → selects an instrument → uploads or connects inputs → receives a scenario → checks invalidation/risk → returns for another session → pays`

No trading-user journey data has been collected yet. The results below are therefore `simulated` and may rank groups, but must not set audience or revenue levels.

## Ranking signal

The simulated coach increase in the value moment was:

1. Parents: +7.8 percentage points
2. Remote workers: +6.2 points
3. Health/55+: +4.7 points
4. Students: +3.5 points

The largest simulated paid-rate increase was also parents, followed by remote workers. This ranking is the only result to carry forward as a hypothesis.

## Trading-product interpretation to test

- **Part-time multi-asset traders** may value a concise brief because they have limited monitoring time.
- **Forex intraday traders** may value off-calendar catalyst detection and explicit invalidation.
- **Stock/index traders** may value earnings and macro-event synthesis.
- **Commodities/crypto traders** may value headline monitoring and volatility-risk warnings.
- **Educators and communities** may value repeatable explanations and shared workflows.

These are product hypotheses, not simulated measurements. A real pilot must measure instrument selection, input completion, scenario usefulness, return rate, and willingness to pay.

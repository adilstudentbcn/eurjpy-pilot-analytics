# Trading product brief — validation pilot

## Status

Working validation specification, 2026-11-01. This is a testable product hypothesis, not evidence of product-market fit.

## Problem

Part-time and multi-asset traders combine charts, calendars, news, price data, and broker tools manually. The resulting workflow can miss off-calendar catalysts and leave the trader without a concise explanation of what could invalidate a scenario.

## Initial target

**Primary pilot segment:** part-time multi-asset traders who review more than one market but cannot monitor every instrument continuously.

**First workflow:** EUR/JPY pre-session planning, using the validated prototype workflow.

**Comparison workflows:** one stock/index workflow and one commodities or crypto workflow.

This is the working target for the pilot. It must be revised if observed activation, repeat use, or qualified interview evidence contradicts it.

## Product promise to test

Given user-supplied market inputs, produce a concise, instrument-aware brief that separates observed evidence from interpretation, identifies relevant scheduled and off-calendar risks, states scenarios, and gives explicit invalidation conditions.

## Success metric

The primary metric is **qualified brief activation**:

> The share of eligible pilot users who select an instrument, provide the required inputs, receive a brief, and rate it useful enough to use for a real planning session.

Track the funnel as separate conditional rates:

1. landing-page visit → instrument selected;
2. instrument selected → input upload/connect intent;
3. input intent → required inputs completed;
4. inputs completed → brief delivered;
5. brief delivered → useful rating;
6. brief delivered → return within 7 days;
7. qualified user → paid intent or pre-order.

No threshold is assumed yet. Thresholds should be set after the first real pilot cohort is sized and observed.

## Out of scope for this pilot

- automated trade execution;
- claims of profitable trading or guaranteed accuracy;
- a complete market-size estimate;
- broad conclusions about all retail traders;
- replacing the trader's final decision;
- adding social, gamification, or community features before the core workflow is tested.

## Decision this brief supports

Decide whether the core brief workflow deserves a larger trading-specific experiment, and which instrument category should receive the next validation effort.
